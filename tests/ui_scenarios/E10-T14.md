# E10-T13 / T14 / T16 / T17 — Annotate 頁面即迴圈（含內嵌畫布與略過機制）

## 怎麼啟動

```bash
horos init ./loop_demo            # 或用既有專案
# Dataset 頁匯入一批影像（zip 或 horos import <dir>），並先建立類別（例如 box）
horos ui ./loop_demo
# 瀏覽器開 http://localhost:5000/annotate   （舊網址 /loop 會自動轉到這裡）
```

## 測試步驟

### A. Select（零標記冷啟動）

1. 進入 `/annotate`：頂端四步只有 Select 亮起；五個數字卡：to label / labeled / skipped / rounds / model
2. 策略徽章顯示「Spread out」（停留看說明）；滑桿拉到 10，主按鈕同步變成「Pick 10 photos」
3. 按 `%` 切成百分比：滑桿上限 100，按鈕文字帶「· 10%」並換算成張數
4. 徽章下方三組選項會記在專案裡、每回合沿用：**Model**（Auto / Boxes / Masks，選 Boxes 或 Masks 後會多一個尺寸下拉）、
   **Suggestions**（On / Off，關掉就不寫預標記）、**Shapes**（Auto / Box / Polygon，Polygon 會用 SAM 把建議框轉成多邊形）；
   切換立即儲存，Label 步驛的回合徽章會顯示目前的模型
5. 按「Pick N photos」：進度條依序走 embedding → pre-annotating（第一次會下載 DINOv2 與 OWLv2 權重）
6. 完成後自動切到 Label

### B. Label（內嵌畫布、略過、多人）

1. 進度環 `0/N`（N = 回合有效張數；略過的照片不計入分母，補進的計入）；徽章「Round 1 · Spread out」，有預標記時另有「M suggested」徽章
2. 下方畫布直接開在第一張待處理影像；沒有站台頁首，左上按鈕是「‹ All」（回本回合總覽）
3. 接受或修正建議（Suggestions 卡片 Accept / Reject，或直接畫框），存檔後進度環即時更新
4. **略過**：按 `S` 或工具列「Skip」：面板列出相似照片縮圖（預設相似度 0.92，可拉滑桿即時重算），
   全部預設勾選；按「Skip N photos」→ 這幾張標記為 skipped，回合自動從池子補進同樣數量的新照片
   （Toast 顯示「Skipped N · M added」，8 秒內可 Undo 略過；補進的照片保留），佇列重新載入並跳到下一張待處理影像；
   補進的照片繼承被略過那張的分派，也帶有預標記，理由以「replacement for a skipped photo」開頭
5. 略過的照片：Select 卡的 skipped 數字增加、to label 減少、不會再被挑選、不進訓練與統計；
   它們離開本回合的佇列與進度環（All photos 的「Done」篩選以 ⊘ 顯示）
6. 多人：名字欄輸入 `ann, bob` 按分派圖示；點名字膠囊切換各人的佇列；重新整理仍記得自己
7. Train 按鈕未達門檻時反灰並列出原因；達門檻後亮起。「↺ Re-pick」關閉本回合回到 Select
8. 「All photos」開啟全專案畫布（含頁首導覽），可瀏覽與編輯任何照片

### C. Train

1. 按 Train：徽章「Round 1 · rfdetr-nano」，進度條隨 epoch 前進，loss 曲線逐 epoch 出現
2. 「■ Stop」可中止；最佳權重保留，回合回到 Label 並提示
3. 正常結束自動切到 Review

### D. Review

1. 大字顯示驗證指標（優先 val mAP）與相對上一回合的 ▲/▼；四個數字：本回合標記數、labeled、to label、skipped
2. 表格：Round / Step / How / Picked / Labeled / Skipped / Metric / Δ
3. 「Next round」關閉回合回到 Select，徽章變「Model-guided」；「✓ Done」停留在總結；「Evaluate」跳到評估頁

### E. 從 API 驗證（無瀏覽器時）

```bash
curl -s localhost:5000/api/v1/loop | python -m json.tool
curl -s -X POST localhost:5000/api/v1/loop/rounds -H 'content-type: application/json' -d '{"count": 10}'
curl -s localhost:5000/api/v1/loop/rounds/1 | python -m json.tool          # 每張的 score 與 reason
curl -s "localhost:5000/api/v1/images/3/similar?threshold=0.9"             # 相似照片
curl -s -X POST localhost:5000/api/v1/images/skip -H 'content-type: application/json' -d '{"image_ids":[3],"note":"blurry"}'
curl -s -X POST localhost:5000/api/v1/images/restore -H 'content-type: application/json' -d '{"image_ids":[3]}'
```

## 預期結果

不讀說明文字，只跟著亮起的步驟與唯一的主按鈕，可從零標記走完一圈；不適合訓練的照片一鍵連同相似照片略過，
且略過後從挑選、統計與訓練中消失、可還原。

## 已知限制

- 畫布引擎仍在同一個 `canvas.html`，以 `/annotate?embed=1&round=<n>` 內嵌、`?canvas=1` 全視窗；沒有拆成獨立 JS 檔
- 相似照片依賴 DINOv2 向量：第一回合挑選前尚無向量時，面板只能略過單張並說明原因
- 分派為 round robin，重新分派會覆蓋既有歸屬；Stop 之後需再按 Train 才續訓
- 本機沒有無頭瀏覽器，頁面以 curl 與 node --check 驗證，請實際點一遍
