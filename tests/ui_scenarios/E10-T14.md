# E10-T13 / E10-T14 — Active learning loop 頁面（含內嵌畫布）

## 怎麼啟動

```bash
horos init ./loop_demo            # 或用既有專案
# 匯入一批未標記影像（Dataset 頁拖入 zip，或 horos import <dir>），至少先在
# Dataset 頁建立類別（例如 box）
horos ui ./loop_demo
# 瀏覽器開 http://localhost:5000/loop
```

## 測試步驤

### A. 第 1 步 Select（零標記冷啟動）

1. 進入 `/loop`，頂端四步只有「Select」亮起；卡片顯示 unlabeled / labeled / rounds done / model 四個數字
2. 策略徽章顯示 `diversity`（滑鼠停留看到說明）；把滑桿拉到 10，按鈕文字同步變成「Select 10 images」
3. 按 `%` 切換成百分比：滑桿上限變 100，按鈕文字帶括號百分比並換算成張數
4. 按「Select N images」：出現進度條，階段文字依序為 embedding → pre-annotating（第一次會先下載 DINOv2 與 OWLv2 權重）
5. 完成後自動切到第 2 步

### B. 第 2 步 Label（內嵌畫布，多人分派）

1. 左側進度環 `0/N`；徽章顯示 `round 1 · diversity`，若有預標記則另有 `M pre-labels` 徽章
2. 下方 iframe 直接開在本回合第一張未標記影像上，沒有站台頁首，Back 按鈕改為「← Round overview」
3. 在畫布上接受或修正預標記（Review 卡片 Accept / Reject，或直接畫框），存檔後上方進度環即時跳成 `1/N`
4. 按 D 到下一張直到最後一張再按 D：畫布顯示「Round complete」，父頁彈出提示
5. 多人：在名字欄輸入 `ann, bob` 按分派圖示；名字膠囊出現，點 `bob` → iframe 只顯示 bob 的份與未分派影像；重新整理頁面仍記得自己是誰
6. 右側 Train 按鈕在未達門檻時反灰，下方列出阻擋原因（影像數不足、某類別實例不足）；達門檻後亮起
7. 「↺ Re-pick」會關閉本回合並回到第 1 步

### C. 第 3 步 Train

1. 按 Train：切到第 3 步，徽章顯示 `round 1 · rfdetr-nano`，進度條隨 epoch 前進，loss 曲線逐 epoch 出現
2. 按「■ Stop」可中止；最佳權重保留，回合回到第 2 步並顯示錯誤提示
3. 訓練正常結束後自動切到第 4 步

### D. 第 4 步 Review

1. 大字顯示本回合模型的驗證指標與相對上一回合的 ▲/▼ 差值；右側三個數字：本回合花掉的標記數、總標記數、剩餘未標記
2. 表格列出每回合：state / how / picked / labels / metric / Δ
3. 「Next round」關閉本回合回到第 1 步，此時策略徽章變成 `pal`（已有模型）；第二回合的 Select 進度會多出 scoring labeled / scoring unlabeled 階段
4. 「✓ Done」關閉回合但停留在總結頁；「Evaluate →」跳到該 run 的評估頁

### E. 從 API 驗證（無瀏覽器時）

```bash
curl -s localhost:5000/api/v1/loop | python -m json.tool          # pool / labeled / next_strategy / rounds
curl -s -X POST localhost:5000/api/v1/loop/rounds -H 'content-type: application/json' -d '{"count": 10}'
curl -s localhost:5000/api/v1/loop/rounds/1 | python -m json.tool  # 每張影像的 score 與 reason
curl -s localhost:5000/api/v1/loop/readiness | python -m json.tool
```

## 預期結果

不讀任何說明文字，只跟著亮起的步驟與唯一的主按鈕，可以從零標記走完 Select → Label → Train → Review 一整圈；
每回合挑選的每張影像都能在 `/api/v1/loop/rounds/<n>` 看到分數與挑選理由。

## 已知限制

- 畫布引擎沒有拆成獨立檔案：它以 `/annotate?embed=1&round=<n>` 的內嵌模式重用整個 annotate 頁
  （隱藏頁首與專案層過濾器），與 loop 頁透過 `postMessage` 溝通進度
- 分派採 round robin，重新分派會覆蓋既有歸屬（已標記的影像不受影響）
- Stop 之後回合回到 Label 步驟，需重新按 Train 才會用保留的權重續訓（尚未提供一鍵 resume）
